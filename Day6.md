# 🚀 Day 6: Network Reconnaissance & Packet Sniffing

## 📝 Summary
Today's objective was to simulate a Red Team vs. Blue Team engagement. The focus was on network discovery, port scanning, firewall evasion techniques, and real-time packet analysis. This exercise demonstrates a practical understanding of how cyber threats probe infrastructure and how defenders monitor these activities at the packet level.

## ✅ Achievements
- [x] **DNS Resolution Configuration:** Edited the `/etc/hosts` file on Server 1 to permanently map Server 2's static IP to its hostname, resolving DNS lookup failures.
- [x] **Firewall Evasion (Red Team):** Successfully utilized Nmap's `-Pn` flag to bypass UFW's ICMP (ping) block/stealth mode on the target node.
- [x] **Service & Version Detection:** Executed advanced Nmap scans (`-sV`) to uncover open ports and identify running service versions (e.g., OpenSSH) on the target.
- [x] **Packet Sniffing (Blue Team):** Installed and deployed `tcpdump` on Server 2 to monitor incoming network traffic in real-time.
- [x] **Live Attack Visualization:** Successfully captured and analyzed the packet flood generated by the Nmap scan from Server 1, filtering out SSH traffic (`port not 22`) to isolate the attack signature.
